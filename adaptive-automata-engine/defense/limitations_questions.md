# Research Defense: Limitations & Scope Q&A

### Q1: What are the main limitations of this research?
**A**:
1. Synthetic Protocol Scope: Experiments evaluate synthetic protocol state spaces; real-world hardware deployments may feature additional jitter.
2. Evidence Accumulation Latency: Adaptation to valid protocol extensions is intentionally non-instantaneous to block poisoning attacks.
3. Python Runtime Bounds: Multi-gigabit line-rate processing requires C/C++ native packet tokenization wrappers.
