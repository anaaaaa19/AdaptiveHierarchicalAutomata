# Patent Invention Disclosure Package Overview

**Title**: Adaptive Hierarchical Automata Engine and Methods for Real-Time Protocol Deviation Detection and Poisoning-Resistant Model Evolution

---

## Technical Field
This disclosure relates generally to computer network security, protocol verification, and automated automata inference, and more particularly to real-time protocol monitoring using hierarchical state machines with formal, poisoning-resistant model adaptation.
