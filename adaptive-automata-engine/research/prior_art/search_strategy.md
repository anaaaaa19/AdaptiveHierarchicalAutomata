# Literature & Prior-Art Search Strategy

This document outlines the systematic research search strategy used to identify prior art across academic publications and patent databases.

---

## 1. Search Query Parameters

### Academic Databases
- **Portals**: IEEE Xplore, ACM Digital Library, USENIX Security, Springer, arXiv.
- **Search Strings**:
  - `"protocol inference" AND "adaptive automata"`
  - `"hierarchical automata" AND "intrusion detection"`
  - `"L* algorithm" AND "mealy machine" AND "protocol security"`
  - `"concept drift" AND "automata model update" AND "poisoning resistance"`

### Patent Databases
- **Portals**: USPTO, EPO (Espacenet), WIPO Patentscope, Google Patents.
- **IPC / CPC Classifications**:
  - `H04L 63/14` (Intrusion detection / Network security)
  - `G06F 21/55` (Detecting malware or unauthorized activity)
  - `G06F 40/20` (Natural language processing / Formal grammars)

---

## 2. Inclusion & Exclusion Criteria

- **Inclusion**: Papers and patents covering active/passive automata learning applied to network protocol monitoring, hierarchical parsing, and model adaptation.
- **Exclusion**: Generic non-sequential machine learning classifiers (e.g. static random forests without state machine graphs) and non-adaptive static firewalls.
